Веб-ремастер **B.A.D. — Blasting, Annihilation & Destruction**, DOS-скроллера
1997 года от Pseudos Software, изданного Webfoot Technologies.

**[Играть](https://chegleyev.github.io/bad/)**

Оригинал тяжело запустить на чём-либо, сделанном в этом веке. Это та же игра,
пересобранная так, чтобы открываться в браузере.

## Управление

Стрелки или **WASD** — движение, **Space** или **J** — огонь.

| | |
| --- | --- |
| **B** | магазин, не выходя из уровня |
| **Esc** | пауза |
| **M** | звук |
| **H** | увеличенные спрайты |

Оба переключателя продублированы в шапке, и оба запоминаются между заходами.

## Что это

Симуляция не переосмыслена, а переписана с оригинала: движение в формате с
фиксированной точкой, его собственные силуэты для столкновений и его такт
**70.0863 Гц** — частота кадровой развёртки подкрученного режима VGA, в которой
измерена каждая скорость в игре. Рендер интерполирует между тактами, поэтому
60, 144 и 240 Гц выглядят одинаково правильно и ни один из них не меняет игру.

Оболочка вокруг — новая. Меню, HUD, магазин и таблица рекордов оригинал не
повторяют: от него им досталась манера и больше ничего.

Три вещи настраиваются параметром в адресе:

* `?hi=1` выключает увеличенные спрайты. Они запечены в 2x нейросетью для
  пиксель-арта и подмешаны обратно к жёсткому ближайшему соседу, чтобы
  сохранился дизеринг.
* `?crt=0` убирает вуаль строк развёртки, `?crt=3` кладёт её погуще. По
  умолчанию 1.5, а шаг полос равен одной строке из оригинальных 350.
* `?stats=1` включает строку счётчиков под полем — такт, объекты, снаряды,
  дропы, кадры в секунду. Это отладочный вывод, по умолчанию его нет.

Два правила намеренно отличаются от оригинала:

* **« SIDE SPEED UP » упирается в четырёхкратную стартовую скорость.** В
  `sub_1e8b` потолка нет вообще, и на длинной дистанции корабль начинает
  пересекать поле быстрее, чем по нему успеваешь целиться.
* **Предмет, которому нечего дать, стоит 50 кредитов.** Полный магазин, пушка
  на потолке урона, перезарядка на минимуме, целый корпус, максимальная
  скорость — оригинал всё это просто роняет на пол. Наказывать за то, что игра
  идёт хорошо, — не та механика, которую стоит сохранять. Компенсация выдаётся
  собственным предметом игры « 50 CREDITS », им же и объявляется. Покупка
  такого в магазине по-прежнему ничего не возвращает.

## Сборка

    npm install
    npm run dev        # http://127.0.0.1:5173
    npm run build      # -> dist/
    npm run preview    # посмотреть собранное
    npm test           # симуляция, без браузера

Кроме Node ничего не нужно: декодированные данные игры лежат в `public/data`.
